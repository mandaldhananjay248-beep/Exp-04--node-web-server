EXPERIMENT04NODE + EXPRESS
01

What is Node.js?

Node.js is a runtime that lets JavaScript run outside a web browser. In this experiment, it runs the server program and listens for browser requests.

RUNTIME
02

What is Express.js?

Express is a lightweight web framework for Node.js. It makes it straightforward to define URL routes and serve files in response to HTTP requests.

FRAMEWORK
03

What is a static file?

A static file is sent to the browser as it is stored, rather than being generated from database records. HTML, CSS, JavaScript, and images can all be static files.

ASSET
04

How does this experiment work?

Express maps /, /about, and /contact to HTML files. Its static middleware makes the contents of public/ available to the browser.

REQUEST → RESPONSE

ONE REQUEST, SIX STEPS

The route to a rendered page

HOW IT WORKS
  1. 01

    Browser sends a request

    You visit a URL, and the browser sends an HTTP request to the server.

    GET /about
  2. 02

    Express receives it

    The Express application receives the request on its local port.

    localhost:3000
  3. 03

    A route is matched

    The URL is matched to a route in server.js.

    app.get('/about')
  4. 04

    The HTML file is returned

    Express sends the matching HTML page as the response.

    about.html
  5. 05

    The browser loads assets

    Static middleware serves the linked CSS and JavaScript files from public/.

    public/css · public/js
  6. 06

    The page becomes interactive

    The browser renders the page and runs its client-side JavaScript.

    HTML + CSS + JS

EXPERIMENT OBJECTIVE

Learn by following
the response.

The purpose is to learn how a Node.js server can deliver static HTML pages using Express. By tracing each URL to a file, the relationship between server routes and browser assets becomes visible.
